# Dicedle

A small, dependency-free Wordle-inspired game foundation.

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server.

## Current foundation

- Responsive game shell and visual identity
- Six guesses of a six-letter answer
- Keyboard and physical keyboard input
- Exact / close / miss tile feedback
- Help and stats modal scaffolding
- Reset/new-roll interaction

The answer is currently configured in `script.js` so the next step can replace it with a daily puzzle source.
