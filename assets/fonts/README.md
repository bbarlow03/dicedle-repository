# Arcade fonts

- Press Start 2P by CodeMan38: `PressStart2P-Regular.ttf`, licensed under
  `PressStart2P-OFL.txt`. Source: https://github.com/google/fonts/tree/main/ofl/pressstart2p
- VT323 by Peter Hull: `VT323-Regular.ttf`, licensed under `VT323-OFL.txt`.
  Source: https://github.com/google/fonts/tree/main/ofl/vt323

The font files are served locally so the arcade design does not depend on
external Google Fonts requests. The original license notices are preserved.
